# TypeTalk AI
### Advanced Voice Typing & AI Assistant for NVDA (v2.0)

**TypeTalk AI** is an intelligent voice typing assistant built specifically for NVDA users. It is powered by **Google Speech Services** and advanced **Artificial Intelligence** models to ensure high-accuracy dictation, smart text processing, and context-aware communication.

## Features
* **Smart Dictation:** High-accuracy speech-to-text using Google Speech Recognition.
* **Smart Reply Generator:** Automatically generates natural replies for chat apps (WhatsApp, Telegram) using context.
* **AI Writing Styles:** Instantly change text tone (Formal, Casual, Concise, Bullet Points).
* **Text Recovery:** Never lose your text—recover the last processed result instantly.
* **AI Intelligence:** Automatic grammar correction, smart punctuation, and formatting.
* **Translation:** Real-time translation to English and other languages.
* **Custom Dictionary:** Define custom voice commands for punctuation or phrases (Works Offline & Online).
* **Emoji Support:** Context-aware AI-suggested emojis.

## How to Use
1. Press **NVDA + Shift + Space** to activate command mode.
2. Press **S** to Start/Stop dictation.
3. Press **R** to Refine or Translate selected text.
4. Press **C** to Set Context (friend's message) and **G** to Generate a Smart Reply.
5. Press **W** to Change Writing Style/Tone.
6. Press **Q** to Check Status (Language/Model/Settings).
7. Press **B** to Recover the last generated text.
8. Press **H** to open the full Help menu.
